Go-Proxy

Fetch and inspect URLs

A tiny HTTP proxy for GET requests, plus a redirect inspector that shows every hop.

Proxy

Fetch a page through this server. The response opens in a new tab.

Redirect Inspector

Follow a URL's redirect chain and see the status code and headers at each hop.

Enter a URL above to trace its redirects.

Usage

Both tools are plain GET endpoints, so they work from the command line too.

curl "$GO_PROXY/proxy?url=https://example.com"
curl "$GO_PROXY/redirect?url=https://example.com"
Only GET is supported. Source on GitHub
